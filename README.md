# DevLink – Developer Resource Hub

DevLink is a simple developer resource hub built with **Next.js** and **Mantine UI**. It helps developers discover useful tools, libraries, APIs, icons, and other resources in one place.

## 🔗 Live Preview

[View DevLink Live](https://devlink-dclg.vercel.app)

## ✨ Features

* Search resources by title, description, or tags.
* Filter resources by category.
* Save and remove bookmarks.
* View saved resources only.
* Quick View for resource details.
* Visit resources through external links.
* Responsive layout for different screen sizes.
* Bookmarks are saved using browser `localStorage`.
* Search and category filters are reflected in the URL.

## 🛠️ Built With

* **Next.js**
* **React**
* **Mantine UI**
* **Tabler Icons**
* **JavaScript**
* **CSS**
